داشبورد محلی چک‌ها — بدون GitHub و بدون data.json

فایل‌های لازم را کنار هم قرار بده:
- cheques.xlsm (فایل اصلی اکسل)
- update_data.py
- index_template.html

روش استفاده:
1) اگر لازم بود، در CMD اجرا کن: py -m pip install openpyxl
2) update_data.py را دوبار کلیک کن.
3) برنامه index.html را در همین پوشه می‌سازد یا به‌روزرسانی می‌کند.
4) برای دیدن صفحه، روی index.html دوبار کلیک کن.

هر بار اکسل را تغییر دادی، فقط update_data.py را دوباره اجرا کن.
اطلاعات در خود index.html جاسازی می‌شوند؛ data.json، اینترنت و GitHub لازم نیست.
فایل اکسل فقط خوانده می‌شود و تغییر نمی‌کند. موفقیت‌آمیز بودن اجرا باعث بسته‌شدن خودکار پنجره می‌شود.
